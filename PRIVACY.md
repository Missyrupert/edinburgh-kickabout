# Privacy

- **No tracking.** There are no analytics, advertising or tracking SDKs, no cookies and no accounts.
- **Saves stay on your device.** Progress, pocket money, unlocks and settings are stored in your browser's localStorage. Nothing is uploaded. Clearing site data (or Settings → Reset progress) removes them.
- **Hosting.** The game is served by GitHub Pages. GitHub may log visitors' IP addresses and request details for security and operations; see GitHub's privacy statement: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
